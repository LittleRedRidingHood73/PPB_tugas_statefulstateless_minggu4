## Tahapan Pemrograman

### 1. Setup Isar

#### 1.1 Menambahkan Dependensi Isar
Langkah pertama adalah menambahkan dependensi Isar dalam proyek Flutter Anda. Buka file `pubspec.yaml` dan tambahkan dependensi berikut:

```yaml
dependencies:
  flutter:
    sdk: flutter
  isar: ^3.0.0 # Pastikan menggunakan versi terbaru
  isar_flutter_libs: ^3.0.0
